# Routing

Hard Boiled's router is deliberately close to Express: methods on `app`, path
params with `:name`, and a wildcard `*`.

## Basic routes

```python
@app.get("/")
async def index(req, res):
    res.json({"message": "hello"})

@app.post("/users")
async def create_user(req, res):
    body = req.json()
    res.status(201).json({"created": body})
```

Supported methods: `app.get`, `app.post`, `app.put`, `app.delete`.

## Path parameters

```python
@app.get("/users/:id")
async def get_user(req, res):
    user_id = req.params["id"]
    res.json({"user_id": user_id})
```

Multiple params work as expected: `/posts/:post_id/comments/:comment_id`.

## Wildcards

```python
@app.get("/files/*")
async def serve_file(req, res):
    path = req.params["wildcard"]
    res.json({"path": path})
```

## Query strings

Query parameters are parsed separately from path params:

```python
# GET /search?q=hardboiled&limit=10
@app.get("/search")
async def search(req, res):
    query = req.query.get("q")
    limit = req.query.get("limit")
    res.json({"query": query, "limit": limit})
```

## Per-route middleware

Any route can take a `middlewares` list, run only for that route (as opposed
to `app.use(...)`, which runs globally on every request):

```python
from middlewares.auth_middleware import jwt_auth_middleware

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

See [Middleware](08.Middleware.md) for how the execution order works, and
[Authentication](09.Authentication.md) for `jwt_auth_middleware` itself.

## Documenting a route for Swagger

Any route can also take a `doc` dict, picked up by [API Docs](10.API-Docs.md):

```python
@app.get("/users/:id", doc={"summary": "Get a user by id", "tags": ["users"]})
async def get_user(req, res):
    ...
```

## 404s

Unmatched routes automatically return `404` with `{"error": "Not Found"}` —
no need to define a catch-all yourself.

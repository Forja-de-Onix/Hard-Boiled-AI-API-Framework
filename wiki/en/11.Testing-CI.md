# Testing & CI

## pytest

```bash
pip install -r requirements-dev.txt
pytest
```

`pytest.ini` sets `asyncio_mode = auto`, so `async def test_...` functions
run without decorating each one with `@pytest.mark.asyncio` — needed since
virtually everything in Hard Boiled is async.

Test files go in `tests/`, following `test_*.py` naming. See
[Quick Start](06.Quick-Start.md) for worked examples.

## GitHub Actions

A minimal workflow (`.github/workflows/tests.yml`) installs dependencies and
runs pytest on every push and pull request. It deliberately does **not**
include deployment steps — those are specific to your hosting setup and
outside the framework's scope.

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.13"
      - run: pip install -r requirements-dev.txt
      - run: pytest
```

If your tests touch the database or an AI connector, add the matching
install step (e.g. `pip install sqlalchemy[asyncio] asyncpg` or
`pip install httpx`) before the `pytest` step.

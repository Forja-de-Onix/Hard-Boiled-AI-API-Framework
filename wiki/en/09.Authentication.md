# Authentication

Hard Boiled includes JWT authentication and password hashing in the core
(`hardboiled/auth.py`) — using only the Python standard library (`hashlib`,
`hmac`, `base64`), so no dependency is required for auth either.

## Tokens

```python
from hardboiled.auth import create_token, decode_token

token = create_token({"sub": user_id, "email": email})
payload = decode_token(token)  # raises ValueError if invalid or expired
```

`JWT_SECRET` (required) and `JWT_EXPIRES_IN` (seconds, default `3600`) are
read from `.env`.

## Password hashing

Uses `hashlib.scrypt`, memory-hard and resistant to brute-force, built into
the standard library:

```python
from hardboiled.auth import hash_password, verify_password

stored = hash_password("my-password")
verify_password("my-password", stored)  # True
```

## Protecting a route

`middlewares/auth_middleware.py` (app layer — yours to extend, e.g. with role
checks) validates the `Authorization: Bearer <token>` header and attaches the
decoded payload to `req.user`:

```python
from middlewares.auth_middleware import jwt_auth_middleware

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

Apply it per-route (see [Routing](07.Routing.md)) — never with `app.use()`,
or you'd also lock out `/login` itself.

## Trying it with curl

```bash
curl -X POST localhost:3000/login \
  -H "Content-Type: application/json" \
  -d '{"email": "demo@hardboiled.dev", "password": "demo1234"}'

curl localhost:3000/me -H "Authorization: Bearer <token>"
```

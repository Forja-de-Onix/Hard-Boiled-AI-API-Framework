# Setup

Hard Boiled is configured entirely through a `.env` file at the root of your project — no framework code needs to be touched to change database engine, AI provider, or streaming behavior.

## 1. Copy the example file

```bash
cp .env.example .env
```

## 2. Choose your database engine

Set `DB_ENGINE` to one of `postgres`, `mysql`, or `mongo`.

- **Postgres / MySQL** (via SQLAlchemy): fill in `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.
- **MongoDB** (via Mongoengine/Motor): fill in `MONGO_URI` instead, and leave the SQL variables as-is.

`hardboiled/database.py` reads `DB_ENGINE` and wires up the correct connection automatically — you never import SQLAlchemy or Mongoengine directly in `database.py` unless you're extending it.

## 3. Choose your AI connector

Set `AI_CONNECTOR` to one of `ollama`, `claude`, `gemini`, or `chatgpt`.

- **Ollama** works out of the box against a local instance (`OLLAMA_HOST`, `OLLAMA_DEFAULT_MODEL` are pre-filled).
- **Claude / Gemini / ChatGPT** require uncommenting and filling in the matching API key block (`CLAUDE_API_KEY`, `GEMINI_API_KEY`, `OPENAI_API_KEY`) and, optionally, the default model.

`hardboiled/connectors.py` picks the active connector based on `AI_CONNECTOR` — your app code calls a single unified interface regardless of provider.

## 4. Set streaming behavior

`STREAM_DEFAULT` controls whether AI responses stream token-by-token (`true`) or return as a single completed response (`false`) when your endpoint doesn't explicitly override it.

## Design principles

1. **No dependencies in the core.** The HTTP server, routing, middleware pipeline, JWT auth, and OpenAPI generation all run on pure `asyncio` and the standard library.
2. **Express-inspired ergonomics.** Familiar `app.get/post/put/delete`, path params, and `app.use()` middleware.
3. **Modern Python feel.** The `Response` API mirrors `httpx` where it makes sense.
4. **Configuration over code.** Database engine and AI provider are chosen via `.env`, not by editing framework internals.
5. **Core vs. app separation.** `hardboiled/` (app.py, router.py, connectors.py, database.py, auth.py, openapi.py) is framework-owned; `controllers/`, `routes/`, `models/`, `middlewares/` at the project root belong to you.

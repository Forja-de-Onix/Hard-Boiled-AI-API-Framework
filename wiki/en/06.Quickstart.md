# Quick Start

This walks through everything currently in the framework: routing,
middleware, database init, AI connectors, JWT auth, and Swagger docs.

## 0. Install & configure

```bash
git clone https://github.com/Forja-de-Onix/Hard-Boiled-AI-API-Framework.git
cd hard-boiled-ai-api-framework
cp .env.example .env
pip install httpx  # needed by all AI connectors, including Ollama
```

Install the database driver matching your chosen `DB_ENGINE` — see
[Database](05.Database.md). Edit `.env` — see [Setup](02.Setup.md) — setting
at least `AI_CONNECTOR`, `JWT_SECRET`, and your database variables.

## 1. Hello world

`main.py`:
```python
from hardboiled import App
from hardboiled.config import load_env

load_env()
app = App()

@app.get("/")
async def index(req, res):
    res.json({"message": "Hard Boiled is running"})

if __name__ == "__main__":
    app.listen(3000)
```

```bash
python main.py
curl localhost:3000/
```

## 2. Add routing and middleware

```python
async def logger_middleware(req, res, next):
    print(f"{req.method} {req.path}")
    await next()

app.use(logger_middleware)

@app.get("/users/:id")
async def get_user(req, res):
    res.json({"user_id": req.params["id"]})
```

See [Routing](07.Routing.md) and [Middleware](08.Middleware.md) for the full
picture.

## 3. Initialize the database

```python
from hardboiled.database import init_database

init_database()
```

See [Database](05.Database.md) for using `get_session()` (SQL) or
`get_mongo_db()` (Mongo) inside a controller.

## 4. Ask the AI

```python
from hardboiled.ai_response import ask

@app.post("/ask")
async def ask_endpoint(req, res):
    body = req.json()
    result = await ask(body["prompt"], stream=body.get("stream"))
    if hasattr(result, "__aiter__"):
        res.stream(result)
    else:
        res.json({"response": result})
```

```bash
curl -N -X POST localhost:3000/ask -H "Content-Type: application/json" -d '{"prompt": "hola"}'
```

The `-N` flag matters — see [AI & Connectors](04.AI-Connectors.md).

## 5. Add JWT login and a protected route

```python
from hardboiled.auth import create_token, hash_password, verify_password
from middlewares.auth_middleware import jwt_auth_middleware

_DEMO_USER = {"id": 1, "email": "demo@hardboiled.dev", "password_hash": hash_password("demo1234")}

@app.post("/login")
async def login(req, res):
    body = req.json()
    if body.get("email") != _DEMO_USER["email"] or not verify_password(body.get("password", ""), _DEMO_USER["password_hash"]):
        res.status(401).json({"error": "Invalid credentials"})
        return
    res.json({"token": create_token({"sub": _DEMO_USER["id"], "email": _DEMO_USER["email"]})})

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

```bash
curl -X POST localhost:3000/login -H "Content-Type: application/json" -d '{"email":"demo@hardboiled.dev","password":"demo1234"}'
curl localhost:3000/me -H "Authorization: Bearer <token>"
```

Replace `_DEMO_USER` with a real lookup against your database once you have
a `users` table/collection — see [Database](05.Database.md).

## 6. Enable API docs

# API Docs (Swagger)

Hard Boiled generates an OpenAPI spec by hand (`hardboiled/openapi.py`, no
dependency) and serves Swagger UI from a CDN — nothing to `pip install`.

## Enabling it

```python
app.enable_docs()  # mounts GET /docs and GET /openapi.json
```

## Documenting a route

Pass a `doc` dict to any route:

```python
@app.post("/login", doc={
    "summary": "Log in",
    "tags": ["auth"],
    "request_body": {
        "type": "object",
        "properties": {
            "email": {"type": "string"},
            "password": {"type": "string"},
        },
        "required": ["email", "password"],
    },
    "responses": {
        "200": {"description": "JWT token issued"},
        "401": {"description": "Invalid credentials"},
    },
})
async def login(req, res):
    ...
```

`doc` accepts: `summary`, `description`, `tags`, `request_body` (a JSON
Schema dict), `responses`, `security`.

## Viewing it

With the server running, visit `http://localhost:3000/docs`. The raw spec is
at `http://localhost:3000/openapi.json`.

## Note on the CDN

Swagger UI assets load from `unpkg.com` in the browser — the framework
itself makes no outbound calls. If you need docs fully offline, vendor the
`swagger-ui-dist` assets yourself and point `enable_docs()` at local paths.

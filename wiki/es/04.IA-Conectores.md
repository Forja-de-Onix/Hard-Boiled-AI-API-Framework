# IA y Conectores

Hard Boiled se comunica con proveedores de IA a través de una interfaz única,
de modo que el código de tu app nunca necesita saber qué proveedor está
activo — eso lo decide solo el `.env`.

## Arquitectura

```
hardboiled/
├── connectors.py # Clases específicas por proveedor (Ollama, Claude, Gemini, ChatGPT)
└── ai_response.py # Función ask() agnóstica del proveedor, usada por tu app
```


- **`connectors.py`** — cada proveedor es una clase que hereda de `AIConnector`,
  que define la interfaz común (`chat`, `chat_stream`) y obtiene su propia
  configuración (API keys, host, modelo por defecto) de las variables de
  entorno definidas en `.env`. Este archivo es núcleo del framework — por lo
  general no se edita.
- **`ai_response.py`** — una capa fina que resuelve el conector activo con
  `get_connector()` y expone una única función `ask()`. No sabe nada de HTTP
  ni de ningún proveedor concreto; solo decide *si* hacer streaming, según
  `STREAM_DEFAULT` (o un override explícito).

## Elegir un proveedor

Establece `AI_CONNECTOR` en `.env` como `ollama`, `claude`, `gemini` o
`chatgpt`. Consulta [Setup](Setup.md) para ver todas las variables que
necesita cada proveedor.

## Usar `ask()` en tu propio código

```python
from hardboiled.ai_response import ask

# Sin streaming: devuelve un string
respuesta = await ask("¿Cuál es la capital de Francia?", stream=False)

# Con streaming: devuelve un async generator de trozos de texto
stream = await ask("Escríbeme una historia larga", stream=True)
async for trozo in stream:
    print(trozo, end="", flush=True)
```

`stream=None` (el valor por defecto) usa `STREAM_DEFAULT` del `.env`.

## Conectarlo a un endpoint HTTP

`res.stream(...)` acepta cualquier async generator y lo sirve como HTTP
chunked:

```python
from hardboiled.ai_response import ask

@app.post("/ask")
async def ask_endpoint(req, res):
    body = req.json()
    result = await ask(body["prompt"], model=body.get("model"), stream=body.get("stream"))

    if hasattr(result, "__aiter__"):
        res.stream(result)
    else:
        res.json({"response": result})
```

## Probarlo con curl

Las respuestas en streaming usan chunked transfer encoding, y por defecto
`curl` bufferea la salida en ciertas condiciones antes de imprimirla. Para
verla llegar progresivamente, usa siempre `-N` (o `--no-buffer`):

```bash
curl -N -X POST http://localhost:3000/ask \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Cuéntame una historia larga sobre un cuervo y un zorro"}'
```

Sin `-N`, la petición sigue streameando correctamente a nivel de red — solo
que no *verás* que llega progresivamente en tu terminal, porque curl retiene
la salida hasta que termina la respuesta.

Para forzar una respuesta sin streaming (un único objeto JSON):

```bash
curl -X POST http://localhost:3000/ask \
  -H "Content-Type: application/json" \
  -d '{"prompt": "hola", "stream": false}'
```

## Añadir un nuevo proveedor

1. Añade una clase en `connectors.py` que herede de `AIConnector`,
   implementando `_get_default_model`, `chat` y `chat_stream`.
2. Regístrala en el diccionario `_CONNECTORS`.
3. Documenta sus variables `.env` necesarias en [Setup](Setup.md).

`ai_response.py` no necesita ningún cambio — solo depende de la interfaz
común `AIConnector`.

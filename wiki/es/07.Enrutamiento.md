# Enrutamiento

El router de Hard Boiled está deliberadamente cerca de Express: métodos sobre
`app`, parámetros de ruta con `:nombre`, y un wildcard `*`.

## Rutas básicas

```python
@app.get("/")
async def index(req, res):
    res.json({"message": "hola"})

@app.post("/users")
async def create_user(req, res):
    body = req.json()
    res.status(201).json({"created": body})
```

Métodos soportados: `app.get`, `app.post`, `app.put`, `app.delete`.

## Parámetros de ruta

```python
@app.get("/users/:id")
async def get_user(req, res):
    user_id = req.params["id"]
    res.json({"user_id": user_id})
```

Varios parámetros funcionan tal cual esperarías: `/posts/:post_id/comments/:comment_id`.

## Wildcards

```python
@app.get("/files/*")
async def serve_file(req, res):
    path = req.params["wildcard"]
    res.json({"path": path})
```

## Query strings

Los parámetros de query se parsean por separado de los de ruta:

```python
# GET /search?q=hardboiled&limit=10
@app.get("/search")
async def search(req, res):
    query = req.query.get("q")
    limit = req.query.get("limit")
    res.json({"query": query, "limit": limit})
```

## Middleware por ruta

Cualquier ruta puede recibir una lista `middlewares`, que corre solo para esa
ruta (a diferencia de `app.use(...)`, que corre globalmente en cada request):

```python
from middlewares.auth_middleware import jwt_auth_middleware

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

Consulta [Middlewares](08.Middlewares.md) para el orden de ejecución, y
[Autenticación](09.Autenticacion.md) para `jwt_auth_middleware` en sí.

## Documentar una ruta para Swagger

Cualquier ruta también puede recibir un dict `doc`, usado por
[Documentación de la API](10.Documentacion-API.md):

```python
@app.get("/users/:id", doc={"summary": "Obtener un usuario por id", "tags": ["users"]})
async def get_user(req, res):
    ...
```

## 404s

Las rutas sin match devuelven automáticamente `404` con
`{"error": "Not Found"}` — no hace falta definir un catch-all propio.

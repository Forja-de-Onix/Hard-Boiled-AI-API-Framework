# Documentación de la API (Swagger)

Hard Boiled genera el spec de OpenAPI a mano (`hardboiled/openapi.py`, sin
dependencias) y sirve Swagger UI desde un CDN — nada que instalar con `pip`.

## Activarlo

```python
app.enable_docs()  # monta GET /docs y GET /openapi.json
```

## Documentar una ruta

Pasa un dict `doc` a cualquier ruta:

```python
@app.post("/login", doc={
    "summary": "Iniciar sesión",
    "tags": ["auth"],
    "request_body": {
        "type": "object",
        "properties": {
            "email": {"type": "string"},
            "password": {"type": "string"},
        },
        "required": ["email", "password"],
    },
    "responses": {
        "200": {"description": "Token JWT emitido"},
        "401": {"description": "Credenciales inválidas"},
    },
})
async def login(req, res):
    ...
```

`doc` acepta: `summary`, `description`, `tags`, `request_body` (un dict de
JSON Schema), `responses`, `security`.

## Verlo

Con el servidor corriendo, visita `http://localhost:3000/docs`. El spec en
crudo está en `http://localhost:3000/openapi.json`.

## Nota sobre el CDN

Los assets de Swagger UI se cargan desde `unpkg.com` en el navegador — el
framework en sí no hace llamadas salientes. Si necesitas la documentación
totalmente offline, incluye tú mismo los assets de `swagger-ui-dist` y
apunta `enable_docs()` a rutas locales.

# Setup

Hard Boiled se configura íntegramente mediante un archivo `.env` en la raíz de tu proyecto — no hace falta tocar código del framework para cambiar el motor de base de datos, el proveedor de IA o el comportamiento de streaming.

## 1. Copia el archivo de ejemplo

```bash
cp .env.example .env
```

## 2. Elige tu motor de base de datos

Establece `DB_ENGINE` en `postgres`, `mysql` o `mongo`.

- **Postgres / MySQL** (vía SQLAlchemy): rellena `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.
- **MongoDB** (vía Mongoengine/Motor): rellena `MONGO_URI` en su lugar, y deja las variables SQL tal cual.

`hardboiled/database.py` lee `DB_ENGINE` y conecta automáticamente con lo correcto — nunca importas SQLAlchemy o Mongoengine directamente salvo que estés extendiendo el propio `database.py`.

## 3. Elige tu conector de IA

Establece `AI_CONNECTOR` en `ollama`, `claude`, `gemini` o `chatgpt`.

- **Ollama** funciona de fábrica contra una instancia local (`OLLAMA_HOST`, `OLLAMA_DEFAULT_MODEL` ya vienen rellenos).
- **Claude / Gemini / ChatGPT** requieren descomentar y rellenar el bloque de API key correspondiente (`CLAUDE_API_KEY`, `GEMINI_API_KEY`, `OPENAI_API_KEY`) y, opcionalmente, el modelo por defecto.

`hardboiled/connectors.py` selecciona el conector activo según `AI_CONNECTOR` — tu código de app llama a una única interfaz unificada sin importar el proveedor.

## 4. Configura el streaming

`STREAM_DEFAULT` controla si las respuestas de IA llegan token a token (`true`) o como una respuesta completa única (`false`) cuando tu endpoint no lo sobreescribe explícitamente.

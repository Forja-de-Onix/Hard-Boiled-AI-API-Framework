# Autenticación

Hard Boiled incluye autenticación JWT y hashing de contraseñas en el núcleo
(`hardboiled/auth.py`) — usando solo la librería estándar de Python
(`hashlib`, `hmac`, `base64`), así que tampoco hace falta ninguna dependencia
para esto.

## Tokens

```python
from hardboiled.auth import create_token, decode_token

token = create_token({"sub": user_id, "email": email})
payload = decode_token(token)  # lanza ValueError si es inválido o expiró
```

`JWT_SECRET` (obligatorio) y `JWT_EXPIRES_IN` (segundos, por defecto `3600`)
se leen de `.env`.

## Hashing de contraseñas

Usa `hashlib.scrypt`, resistente a fuerza bruta y "memory-hard", incluido en
la librería estándar:

```python
from hardboiled.auth import hash_password, verify_password

stored = hash_password("mi-contraseña")
verify_password("mi-contraseña", stored)  # True
```

## Proteger una ruta

`middlewares/auth_middleware.py` (capa de la app — tuya para extender, p. ej.
con comprobación de roles) valida el header `Authorization: Bearer <token>`
y adjunta el payload decodificado a `req.user`:

```python
from middlewares.auth_middleware import jwt_auth_middleware

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

Aplícalo por ruta (ver [Enrutamiento](07.Enrutamiento.md)) — nunca con
`app.use()`, o bloquearías también el propio `/login`.

## Probarlo con curl

```bash
curl -X POST localhost:3000/login \
  -H "Content-Type: application/json" \
  -d '{"email": "demo@hardboiled.dev", "password": "demo1234"}'

curl localhost:3000/me -H "Authorization: Bearer <token>"
```

# Inicio Rápido

Este recorrido cubre todo lo que hay hoy en el framework: enrutamiento,
middlewares, inicialización de base de datos, conectores de IA,
autenticación JWT y documentación Swagger.

## 0. Instalar y configurar

```bash
git clone <url-de-tu-repo>
cd hard-boiled-ai-api-framework
cp .env.example .env
pip install httpx  # necesario para todos los conectores de IA, incluido Ollama
```

Instala el driver de base de datos correspondiente a tu `DB_ENGINE` elegido
— ver [Base de Datos](05.Base-de-Datos.md). Edita `.env` — ver
[Setup](02.Setup.md) — fijando al menos `AI_CONNECTOR`, `JWT_SECRET` y tus
variables de base de datos.

## 1. Hola mundo

`main.py`:
```python
from hardboiled import App
from hardboiled.config import load_env

load_env()
app = App()

@app.get("/")
async def index(req, res):
    res.json({"message": "Hard Boiled funcionando"})

if __name__ == "__main__":
    app.listen(3000)
```

```bash
python main.py
curl localhost:3000/
```

## 2. Añadir enrutamiento y middleware

```python
async def logger_middleware(req, res, next):
    print(f"{req.method} {req.path}")
    await next()

app.use(logger_middleware)

@app.get("/users/:id")
async def get_user(req, res):
    res.json({"user_id": req.params["id"]})
```

Consulta [Enrutamiento](07.Enrutamiento.md) y

Ver [Base de Datos](05.Base-de-Datos.md) para usar `get_session()` (SQL) o

## 4. Preguntar a la IA

```python
from hardboiled.ai_response import ask

@app.post("/ask")
async def ask_endpoint(req, res):
    body = req.json()
    result = await ask(body["prompt"], stream=body.get("stream"))
    if hasattr(result, "__aiter__"):
        res.stream(result)
    else:
        res.json({"response": result})
```

```bash
curl -N -X POST localhost:3000/ask -H "Content-Type: application/json" -d '{"prompt": "hola"}'
```

El flag `-N` importa — ver [IA y Conectores](04.IA-Conectores.md).

## 5. Añadir login JWT y una ruta protegida

```python
from hardboiled.auth import create_token, hash_password, verify_password
from middlewares.auth_middleware import jwt_auth_middleware

_DEMO_USER = {"id": 1, "email": "demo@hardboiled.dev", "password_hash": hash_password("demo1234")}

@app.post("/login")
async def login(req, res):
    body = req.json()
    if body.get("email") != _DEMO_USER["email"] or not verify_password(body.get("password", ""), _DEMO_USER["password_hash"]):
        res.status(401).json({"error": "Credenciales inválidas"})
        return
    res.json({"token": create_token({"sub": _DEMO_USER["id"], "email": _DEMO_USER["email"]})})

@app.get("/me", middlewares=[jwt_auth_middleware])
async def me(req, res):
    res.json({"user": req.user})
```

```bash
curl -X POST localhost:3000/login -H "Content-Type: application/json" -d '{"email":"demo@hardboiled.dev","password":"demo1234"}'
curl localhost:3000/me -H "Authorization: Bearer <token>"
```

Sustituye `_DEMO_USER` por una consulta real a tu base de datos en cuanto
tengas una tabla/colección `users` — ver [Base de Datos](05.Base-de-Datos.md).
